# あそびのもり 超レビュー＋大改造（2026-10-04 / j-0806）

対象：kids-coding-game（「あそびのもり」）全体。ブランチ `feature/j-0806-super-review`。
SHOW の依頼「今まったく稼働していないので何をどういじってもいい。ガラッと変えてもいい」を受けて、
**「子どもが何度も遊びたくなる・親が安心して渡せる」** を軸にレビューし、そのまま直した記録。

## 1. いまのゲームは何で、子どもにとって何が面白く何がつまらないか

**何か**：小1向けの知育ミニゲーム10本＋ごほうび（どんぐり→くじ→きせかえ・かぐ）のアーケード。
単一HTML＋バニラJS、PWA／Android APK でオフライン動作。見た目（ねんど調の生成画像・ユニコーン）は
すでにプロ水準に近く、P0（クラッシュ・進行不能）はゼロだった。

**面白いところ**
- 絵・音・紙吹雪の手ごたえ。触った瞬間に返事が来る（Sfx/FX の共通基盤がよく効いている）。
- 10本のジャンルが広い（記憶・推理・空間・抑制・観察・分類・音感・プログラミング）。
- 失敗しても叱らない作り。

**つまらない／危ないところ（改修前）**
1. **「また あした」がない。** 毎日あそぶ理由が どんぐりだけ。どんぐりも 1時間弱で 21個を集めきると完全な行き止まり。
   きまりは外れても罰なしで総当たりでき、そっくりわけは1ラウンドで くじ1回分以上出るなど、水増しもできた。
2. **ごほうびが ホームから見えない。** せっかく着せ替えても、ホームのユニコーンは いつも同じ。
3. **文字を読めない子への説明が文字頼み。** ヒント1行が唯一の説明。プログラミングのループ導入（L5）も文章カードだけ。
4. **親が安心して渡せない。** 子どもが3タップで全記録を消せる（ホーム／プログラミングの「さいしょ」は
   どんぐりごと消える）。遊びすぎ対策・効果音オフも無い。
5. **小さい画面で崩れる所がある。** かたちのピースがトレイからはみ出して重なる、ぴたごらの升が 26px まで縮む、
   プログラミングのスタートボタンが画面外、など。
6. **うたあそびが「ゲーム」として成立していない所がある。** リングが画面に入る前に弾ける、
   まねうたは音程が外れる子が永遠に進めない、モード直後に戻るとマイクが開いたまま。

## 4. 方針と、大きく変えた点（変えた理由）

**方針**：10本のゲームは どれも作りが良く、作り直すより **「あそびの外側（毎日の動機・親の安心・読めない子への説明）」** を
足すほうが効く、と判断した。ゲーム本体は不具合と小1に合わない所だけを直し、全体の体験を作り直した。

### 4-1. 「きょうの 3つ」（まいにちの スタンプ）— また あした あそびたくなる
- ホームに毎日ちがう3本のおすすめ。どれでも1回 せいこうすると花のスタンプ（ゲーム中にも「スタンプ ゲット！」）。
  3つそろうと **どんぐり＋5**（紙吹雪＋読み上げ）。下に「あそんだ ひ」7日ぶん。
- 10本を3本ずつローテーション（10日で一巡）＝**いろいろな力を まんべんなく使う**。連続日数（ストリーク）は
  あえて数えない（休んだ日に責めない）。
- 判定は「その日はじめて見た `wins`」より増えたか。**ゲーム側のコードは無改修**（rewards.js が `Save.game` を包んで検知）。

### 4-2. ごほうびを「ホームで見える・長く集められる」に
- ホームのヒーローが **きせかえ中の じぶんの ユニコーン** になる（タップで おへやへ）。重ね位置は room と共有（`Rewards.PLACE`）。
- ごほうびを 21→**31種**（まほうの ぼうし・うさみみ・コックさん・サングラス・はなの わ・ほしの かざり・とけい・ピアノ・きんぎょ・つみき）。
  未所持はシルエットで見せて「あれが ほしい」を作る。
- 稼ぎすぎ（きまり総当たり・そっくり1問ごと）を止め、増やした分は毎日のスタンプで出す。

### 4-3. おうちの ひと メニュー — 親が安心して渡せる
- 歯車 → **かけざんゲート**（小1は習わない。外れると閉じる）→ メニュー。
- **あそぶ じかん（1日）**：なし/15/30/45/60ふん。のこり1ぷんで「もうすぐ おしまい」、時間で
  **「きょうは ここまで」**（ねむる ユニコーン・星空。音も止める）。延長はゲートの うしろで「あと10/30ふん」「きょうは なし」。
- **こうかおん**・**こえの あんない** の オン/オフ、**きろくを ぜんぶ けす**（確認つき）。
- プログラミングの「さいしょ」もゲートの うしろへ（どんぐりは消さない）。

### 4-4. こえの あんない（読み上げ）— 読めなくても わかる
- `assets/talk.js`：ヒント1行（`data-talk`）を端末の音声合成（ja-JP・通信しない）で読み上げ。文字が変わると自動、タップで もう一度。
  結果の見出し・ルールカードも読む。うたあそびのマイク中は止める。
- 未対応環境（Android WebView 等）では何もしない＝落ちない。

### 4-5. 見せる導入（プログラミング）
- L1：「みぎ」が光って矢印が指す → 3つ並べると「スタート」が光る。L2/L3/L5/L7：新しいボタンを光らせる。
- 実行中は「スタート」が「とめる」に変わる。

## 6. 見送り・残課題

- **実機確認**：読み上げの声質（端末の音声）・うたあそびのマイク（タブレットのマイク不具合で未検証のまま）・iOS Safari。
- **Android アプリで読み上げ**：WebView は Web Speech の音声合成が使えないため、APK では読み上げが出ない。
  ネイティブ TTS プラグイン（`@capacitor-community/text-to-speech`）を入れれば対応できる（APK の再ビルドが要る）。
- **保存できない環境の警告**（プライベートモード）・記録の書き出し／引き継ぎ。
- **共通シェル化**：5ゲームで重複する CSS/ヘルパーの共通化（今回は動作を壊さないことを優先して見送り）。
- **演出時間のフレーム依存**（fx.js）。
- ぴたごら 360幅の升は 40px（44px にすると 8マスが画面幅を超える）。
